# Pseudolenguaje

El dialecto principal por defecto es estilo PSeInt.

## Estructura base

```text
Algoritmo MiPrograma
    Escribir "Hola"
FinAlgoritmo
```

## Instrucciones soportadas

- `Algoritmo`, `Proceso`, `FinAlgoritmo`, `FinProceso`
- `Definir nombre Como Entero`
- Asignaciones con `<-`
- `Escribir "texto", variable, 2 + 2`
- `Leer variable`
- `Si condicion Entonces ... Sino ... FinSi`
- `Mientras condicion Hacer ... FinMientras`
- `Para i <- inicio Hasta fin Hacer ... FinPara`
- `Segun expresion Hacer ... FinSegun`

## Objetivo

PseudoCode busca crecer hacia una experiencia educativa estilo PSeInt: ejecucion, diagnosticos claros, ayuda integrada, pruebas de escritorio y herramientas de aprendizaje para pseudocodigo en espanol.
